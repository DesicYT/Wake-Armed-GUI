\# Wake-Armed-GUI



\# a small exe python tool to manage wake armed devices. basically, instead of having to use the terminal, you can use this GUI.



"a python tool to see what devices wake from sleep and manage them."



\## 🚀 Features

\* \*\*wake source history:\*\* see what device last woke the pc up from its slumber.

\* \*\*device sorting:\*\* Lists all wake-capable devices in your system, automatically prioritizing active/enabled devices at the top with a `⚙️` indicator.

\* \*\*text filter:\*\* A live search bar to quickly find specific hardware components (e.g., "mouse", "ethernet").

\* \*\*checkboxes:\*\* check or uncheck boxes to toggle hardware wake permissions instantly.



\## 📥 how to download and run



1\. Download \*\*`wake\_manager.exe`\*\* directly from this repository (or from the Releases section).

2\. Move the file anywhere you like (e.g., your Desktop).

3\. Double-click the file to open it.



\### ⚠️ important: administrator rights required

you have to have admin permissions to use powercfg in general so you need to have admin rights to use this tool.
